What Lensy Detects

🔍

Deprecated Code Examples

Identifies code snippets using outdated methods, removed APIs, or syntax that no longer works — with line-specific recommendations.

📊

Documentation Quality Scores

Evaluates your docs across 5 dimensions: Relevance, Freshness, Clarity, Accuracy, and Completeness. See exactly where you're strong and where you're not.

⚠️

Outdated API References

Flags references to deprecated endpoints, removed parameters, and version mismatches between your docs and your actual API.

🔗

Content Gaps & Redundancy

Finds missing documentation, duplicate content, and consolidation opportunities across your doc set.

  • Works With Any Dev Docs — API references, SDK guides, tutorials — if it's developer documentation, Lensy can analyze it
